## ส่วนที่ทำเพิ่มแล้วในรุ่นนี้

### ครูและผู้ดูแล
- จัดการรายวิชา ชื่อวิชา รหัสวิชา คำอธิบาย และห้องเรียน
- ผูกรายวิชากับห้องเรียนและปีการศึกษา/ภาคเรียน กำหนดคาบต่อสัปดาห์ เกณฑ์เวลาเรียน และวิธีนับมาสาย/ลา
- เพิ่มหน่วยการเรียนรู้ ลำดับและลิงก์สื่อ กำหนดการเผยแพร่ให้นักเรียน
- บันทึกการสอนรายคาบ เลือกวัน/คาบ/หัวข้อ เช็คชื่อมา-ขาด-สาย-ลา-อื่น ๆ
- คำนวณร้อยละเวลาเรียนเป็นรายคนจากจำนวนคาบที่จัดสอนจริง ส่งออก CSV; รายการที่ไม่เช็คยังไม่คิดเป็นมาเรียน
- สั่งงาน/กำหนดส่ง/กำหนดคะแนนเต็ม เปิดเผยแพร่งาน ตรวจงานและให้คะแนน/ความคิดเห็นรายคน
- **สมุดคะแนนถ่วงน้ำหนัก:** เพิ่มหมวดคะแนน กำหนดน้ำหนักร้อยละ ตั้งรายการคะแนน กรอกคะแนนแบบตาราง ตั้งเกณฑ์ตัดเกรด 0–4 และแก้ไขได้รายวิชา
- ส่งออกคะแนน CSV และพิมพ์/บันทึกเป็น PDF ผ่านเบราว์เซอร์ พร้อมประวัติการแก้ไขคะแนนในฐานข้อมูล
- เชื่อมรายการคะแนนกับงานที่ครูมอบหมายแล้ว: เมื่อครูตรวจงาน คะแนนจะอัปเดตสมุดคะแนนและย้อนหลังการตรวจงานที่ทำไปแล้วในวิชาเดียวกัน
- ระบบรายการประเมินเดิมเพิ่มการเลือก “เผยแพร่คะแนนให้นักเรียนเห็น” โดยค่าเริ่มต้นเป็นข้อมูลส่วนตัว ไม่เปิดให้นักเรียนอ่านโดยอัตโนมัติ
- เก็บหลักฐาน วPA แยกปีงบประมาณ 2570, 3 ด้าน 15 ตัวชี้วัด แก้ไขตัวชี้วัด เพิ่มหลักฐานและอัปโหลด PDF/DOCX/ภาพแบบส่วนตัว
- ลงผลงานครู ภาพกิจกรรม วิจัย วิดีโอผ่านลิงก์ เกียรติบัตร/รางวัล พร้อมอัปโหลดภาพหน้าปก กำหนดเผยแพร่หรือฉบับร่าง

### นักเรียน
- แยกหน้าเข้าสู่ระบบนักเรียนด้วย Supabase Auth
- นักเรียนหนึ่งบัญชีเชื่อมกับนักเรียนหนึ่งคน (ผ่าน `student_accounts`)
- ดูรายวิชาและหน่วยเรียนเฉพาะที่ครูเผยแพร่สำหรับชั้นเรียน
- ดูร้อยละเวลาเรียนและการเตือนความเสี่ยงต่ำกว่าเกณฑ์
- ดูงานที่ได้รับ กำหนดส่ง ส่งหมายเหตุหรืออัปโหลดไฟล์ส่วนตัว (PDF/DOCX/JPG/PNG ไม่เกิน 10 MB)
- ดูสถานะงานที่ส่ง ผลการตรวจ ความคิดเห็น และคะแนนของตนเอง
- ดูคะแนนรายกิจกรรมจากระบบคะแนนเดิมเฉพาะบัญชีตนเอง

## วิธีเริ่มต้นใช้งานจริง

1. ตรวจ GitHub Actions สำหรับ commit ล่าสุดให้ขึ้น **สีเขียว** และเปิดลิงก์ `studio.html`
2. ลงชื่อด้วยบัญชีครูที่เป็น Admin อยู่แล้วใน Supabase (ไม่มีรหัสผ่านตั้งต้นที่เผยแพร่)
3. เปิด **รายวิชา/ชั้นเรียน** → เพิ่มชื่อวิชาและห้องเรียน หากยังไม่มี → เลือกภาคเรียน → **เปิดสอนรายวิชา** → เลือก `เผยแพร่ให้นักเรียนเห็น`
4. เพิ่มนักเรียนในเมนู **นักเรียน** (หรือใช้ระบบ `../online/` สำหรับนำเข้าข้อมูล)
5. เปิด **เช็คชื่อรายคาบ** → เพิ่มคาบเรียน → บันทึกสถานะและดูสรุปเวลาเรียน
6. เปิด **การบ้านและตรวจงาน** → มอบหมายงาน → เปิดให้นักเรียนเห็น → ตรวจงานเมื่อมีผู้ส่ง
7. เปิด **แฟ้ม วPA** เพื่อเพิ่มหลักฐาน หรือ **ผลงาน/ภาพ/วิดีโอ** เพื่อเผยแพร่ผลงาน
8. ก่อนนักเรียนใช้งาน ให้สร้าง Auth User ของนักเรียนใน Supabase Dashboard ก่อน แล้วนำ **User UID** (ไม่ใช่รหัสผ่าน) มาเชื่อมกับรายชื่อนักเรียนที่ **นักเรียน → เชื่อมบัญชีนักเรียน (Admin)**; จากนั้นนักเรียนจึงเข้าสู่ `student.html` ได้

## โครงสร้างไฟล์ใหม่

- `studio.html`, `studio.js`: ระบบครู/แอดมินแบบหลายเมนู
- `grades.html`, `grades-base.js`, `grades.js`: สมุดคะแนนถ่วงน้ำหนัก ตรวจประวัติแก้ไขและการเผยแพร่คะแนนตามรายวิชา
- `check-site.mjs`: ตรวจ JavaScript และลิงก์ก่อน GitHub Actions Deploy
- `student.html`, `student.js`: พอร์ทัลนักเรียนพร้อมสิทธิ์เฉพาะเจ้าของข้อมูล
- `portfolio.html`: หน้าแสดงผลงานสาธารณะเฉพาะรายการเผยแพร่
- `migrations/*.sql`: ประวัติการเปลี่ยนโครงสร้าง Supabase ที่ **รันแล้ว** (เก็บเป็นซอร์สสำหรับทบทวน/ติดตั้งใหม่ เรียงตามเลขเวอร์ชัน)

**ตารางสมุดคะแนนเพิ่มเติม:** `grade_categories`, `grade_items`, `grade_entries`, `grade_scales`, `grade_history` และ RPC `set_course_grade_scales` — RLS แยกสิทธิ์นักเรียน/ครู

**ตารางข้อมูลสำคัญ:** `academic_terms`, `student_accounts`, `course_sections`, `course_units`, `teaching_sessions`, `period_attendance`, `assignment_tasks`, `assignment_submissions`, `assignment_reviews`, `pa_cycles`, `pa_indicators`, `pa_evidence`, `teacher_portfolio`

**Storage Buckets:** `student-uploads` (private), `teacher-pa-files` (private), `teacher-gallery` (public); ใช้ RLS จำกัดการอัปโหลดตามสิทธิ์

## สิ่งที่ยังไม่ครบตาม MASTER PROMPT และยังไม่ควรอ้างว่าเสร็จ

- โครงสร้าง Next.js/React/TypeScript/Tailwind + การ Deploy Vercel: เว็บไซต์ออนไลน์ปัจจุบันยังใช้ Static JavaScript บน GitHub Pages + Supabase เพื่อรักษาระบบเดิมและค่าใช้จ่าย $0; ยังไม่ได้ย้ายสแตกตาม prompt
- ไม่มีบัญชี Parent และ PA Reviewer พร้อมการแชร์สิทธิ์เฉพาะบุคคล, ยังไม่ได้สร้างระบบสมัครบัญชีนักเรียนอัตโนมัติ
- ยังไม่มีตารางสอนแบบปฏิทินจริง, คัดลอกรายวิชาข้ามภาคเรียน, ระบบ Rubric แบบหลายเกณฑ์, นำเข้า Excel, รายงาน PDF/XLSX โดยตรงแบบไฟล์สำเร็จ (ปัจจุบันพิมพ์/บันทึก PDF ได้ผ่านเบราว์เซอร์และส่งออก CSV)
- ยังไม่มีอัลบั้มหลายภาพแบบ Gallery/Lightbox, อัปโหลดวิดีโอโดยตรง, การเชื่อมข้อมูลเข้า วPA อัตโนมัติ, รายงาน PA PDF อย่างเป็นทางการ, Dark Mode
- ยังไม่มีการทดสอบ E2E จริงด้วยบัญชีครู/นักเรียนและข้อมูลจำลองครบทุกฟังก์ชัน: โปรดทดสอบในเบราว์เซอร์ก่อนใช้ข้อมูลส่วนตัวจริง

## เช็กลิสต์ก่อนใช้งานข้อมูลจริง

- [ ] เปิดเว็บไซต์ครบทุกหน้าและ Deploy ล่าสุดสีเขียว
- [ ] ทดสอบการเข้าสู่ระบบ Admin และการกู้คืนรหัสผ่านจริง
- [ ] สร้างห้องเรียน/รายวิชา/หน่วยเรียนด้วยข้อมูลตัวอย่าง
- [ ] ทดสอบเช็คชื่อ 2 คาบและร้อยละเวลาเรียนตามเกณฑ์
- [ ] ทดสอบเพิ่มหมวดคะแนน 60/40 บันทึกครบ และตรวจผลการเรียน/CSV/ประวัติการแก้ไข
- [ ] สร้างบัญชีนักเรียนทดลองและเชื่อม UID ก่อนเช็คข้อมูลส่วนตัว
- [ ] ทดสอบนักเรียนคนหนึ่งไม่เห็นคะแนน/การเข้าเรียน/ไฟล์ของคนอื่น
- [ ] ทดลองส่งงาน PDF และตรวจงานพร้อมบันทึกคะแนน
- [ ] ตรวจสิทธิ์ไฟล์หลักฐาน PA ที่เป็น private
- [ ] ตรวจสอบสิทธิ์เผยแพร่ภาพนักเรียนตาม PDPA
- [ ] สำรองข้อมูลและเตรียมคู่มือการใช้งานจริง

**ความปลอดภัย:** Supabase RLS ถูกเปิดใช้สำหรับตารางใหม่ทั้งหมด; สิทธิ์ admin ถูกตรวจจากตาราง `profiles` ฝั่งฐานข้อมูล ห้ามนำ secret/service_role key, password หรือข้อมูลเด็กไปใส่ไฟล์สาธารณะ ใช้ข้อมูลสมมติในระหว่างทดสอบ

**ค่าใช้จ่าย:** ไม่ได้อัปเกรด Supabase Free หรือเพิ่มบริการคิดเงิน ค่าใช้จ่ายจะขึ้นกับโควตาฟรีของผู้ให้บริการและการใช้งานจริง
